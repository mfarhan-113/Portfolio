# Muhammad Farhan Portfolio

Modern static portfolio for Muhammad Farhan, built with plain HTML, CSS, and JavaScript.

## What is included

- Premium dark portfolio UI with responsive sections
- Updated experience from the CV
- Featured AI, full-stack, healthcare, RAG, and computer-vision projects
- SEO metadata and structured data
- Static mailto contact flow, no PHP backend
- Downloadable CV at `Farhan-CV.pdf`

## Deploy on Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Use these settings:
   - Framework Preset: `Other`
   - Build Command: leave empty
   - Output Directory: `.`
4. Deploy.

Because this is a static site, Vercel will serve `index.html` directly.
